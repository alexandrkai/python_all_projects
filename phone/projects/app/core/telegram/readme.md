для того, чтобы телега в термуксе телефона работала надо поднять ssh-тунель на иипортный vps-сервер
ssh -D port -N -f user@your_vps_ip
т.е.
ssh -D 9090 -C -N kai@89.125.188.172
а для этого надо сделать ключики для телефона на удаленном сервере
ssh-keygen -t rsa
ssh-copy-id kai@89.125.188.172

ssh -D 9090 -N -f kai@89.125.188.172

autossh — автоматический перезапуск (Рекомендуемый)
Если туннель всё равно падает (например, из-за обрыва сети), autossh автоматически перезапустит его. Это стандартный инструмент для поддержания постоянных туннелей.

1. Установите autossh:

bash
# Для Termux (если есть pkg)
pkg install autossh

2. Запустите туннель через autossh:

bash
autossh -M 0 -f -N -D 9090 -o "ServerAliveInterval=30" -o "ServerAliveCountMax=3" kai@89.125.188.172
-M 0: Отключает встроенный мониторинг autossh и полагается на ServerAliveInterval.

-f: Запускает autossh в фоновом режиме.
